# R1 red proofs on the published 4.19.0 (tag v4.19.0, baa411bb), 2026-10-13

Method: a worktree at v4.19.0; R1's test files copied in (MongoDB, MongoDB.V2, TcpTap, TcpTap.Bson3, core
StatementNoteNullTests, E2E MongoNoteTests and their project files); the one new product type the tests name,
MongoJson, stubbed as the driver's own `value.ToJson()` (how 4.19.0 wrote a document into a note); the internals
access lines added so the projects compile. Real-server facts ran against mongo 7.0.43, a single-node replica set
(KRONIKOL_TEST_MONGO=mongodb://127.0.0.1:27217/?replicaSet=rs0&directConnection=true).

Every failure below is the fact's own assertion, or the defect itself reaching the caller: at Raw the application's
FindOneAndUpdate threw ObjectDisposedException (driver 3.12.0) or OperationCanceledException (2.30.0), a deferred
claim's note threw ObjectDisposedException out of the subscriber, and a throwing redaction hook's exception reached
the caller. The GUID facts were first built with an in-memory BsonBinaryData, which 3.x's writer refuses; they now read
the GUID from BSON, as a reply carries it, and fail on the note's text.

New facts green on 4.19.0, each by design:
- A_content_pattern_written_for_todays_text_still_redacts: a pin (F20). It fails if the writer drops the driver's spacing.
- A_find_reply_offers_the_YAML_view_and_draws_YAML (E2E): on driver 3.x a find's batch was already JSON, indented.
- Every_utf16_unit_is_escaped_as_the_driver_escapes_it, Strings_are_escaped_as_the_driver_escapes_them: the stub is the
  driver's writer, so they hold by construction there; on R1 they hold Kronikol's writer to the driver's escaping.
- Server_state_replies_are_left_out_at_Detailed_and_whole_at_Raw, A_reply_with_nothing_but_bookkeeping_has_no_note:
  guards; 4.19.0 also wrote no note for those replies.
- A_write_that_succeeded_has_no_Error, ASuccessfulReplyHasNoError: guards; 4.19.0 never set Error.
- An_http_body_still_drops_its_nulls: the guard that keeps the null rule to statement notes.
- Every_bson_type_has_a_case, TheShapesHoldEveryKindOfReplyTheRulesTellApart: guards over the facts' own data.
The guards' rules are held by mutations (mutations.txt).
