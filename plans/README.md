# Plans

Design records. Each `*_PLAN.md` here is the working document behind a piece of Kronikol
— the investigation, the measurements, the decisions taken and the ones deliberately not
taken. They are kept after the work ships so the reasoning survives the diff.

A plan is **not** a promise. Some are executed in full, some are partly done, and some are
investigations that were never green-lit. **[`PLANS_STATUS.md`](PLANS_STATUS.md) is the
index**: one row per plan with its status and the release it shipped in.

Nothing in this directory is part of the published packages, and nothing here is
authoritative about current behaviour — for that, see the
[wiki](https://github.com/lemonlion/Kronikol/wiki), the [README](../README.md) and the
[changelog](../CHANGELOG.md).
