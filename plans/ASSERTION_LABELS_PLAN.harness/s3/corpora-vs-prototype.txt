Every difference is one the release decided on purpose:

  - A later Shouldly call reads by Shouldly's rule, as the first does: its type argument without brackets
    (`..., exception should be of type TException`, the prototype `<TException>`). AutoMapper 2, MediatR 1, Marten 9.
  - The comma before a member goes only where the chain moves on from an assertion, so after a later Shouldly call
    too (`..., exception should be of type X, projection name should be ...`, where the prototype read
    `... X projection name ...`). Marten 4 of the 9 above.
  - F13: the one Marten statement with a quote inside an interpolated string's hole keeps the hole's literal as
    written (`{string.Join("\n", stale)}`; the prototype collapsed the probe's line break inside it).
  - Q8: `.And.` and `.Or.` read both halves: chains.txt 2, f6.txt 1 (`X should not be null and have count 2`).
  - F12: comments are not read: edges.txt 2 (`Result should be 5`, `Result total should be expected.Total`).

The third-party suites' statements are not kept (AutoMapper and MediatR are under the Lucky Penny Software licence):
corpus/shouldly_corpora.sh fetches them again at the commits the plan measured.
